# Flight Tracker

Консольное приложение на Python для поиска и отслеживания статусов пассажирских авиарейсов.

Приложение получает данные через Aviationstack API, позволяет сохранять интересующие рейсы в локальную базу SQLite и просматривать историю изменения их статусов.

## Возможности

- Поиск авиарейсов по номеру.
- Получение информации о статусе, авиакомпании, аэропортах и времени вылета и прибытия.
- Сохранение рейсов в список отслеживания.
- Хранение истории изменения статусов.
- Обновление информации о сохранённых рейсах.
- Удаление рейсов из списка отслеживания.
- Демонстрационный режим без подключения к API.
- Обработка ошибок API и сетевых соединений.

## Технологии

- Python 3.10+
- Requests — HTTP-запросы к API.
- SQLite — локальное хранение данных.
- Argparse — обработка аргументов командной строки.
- Pytest — автоматическое тестирование.

## Настройка

Для работы с реальными данными необходим API-ключ Aviationstack.

Получить бесплатный API-ключ можно на сайте:

<https://aviationstack.com/>

Создайте файл `.env` в корневой директории проекта:

```env
AVIATIONSTACK_API_KEY=YOUR_API_KEY
DATABASE_PATH=data/flights.db
API_TIMEOUT=20
```

Замените `YOUR_API_KEY` на собственный API-ключ.

- `AVIATIONSTACK_API_KEY` — ключ доступа к Aviationstack API.
- `DATABASE_PATH` — путь к локальной базе данных SQLite.
- `API_TIMEOUT` — максимальное время ожидания ответа API в секундах.

Файл `.env` содержит конфиденциальные данные и не должен попадать в Git-репозиторий.

## Использование

### Поиск рейсов

Поиск по номеру рейса:

```bash
flight-tracker search BA249
```

Поиск с указанием даты:

```bash
flight-tracker search BA249 --date 2026-11-12
```

Поиск без указания даты использует доступные данные реального времени.

**Примечание:** поиск за произвольную дату требует доступа к историческим данным Aviationstack и зависит от тарифного плана.

### Добавление рейса в отслеживание

```bash
flight-tracker watch BA249
```

### Просмотр отслеживаемых рейсов

```bash
flight-tracker list
```

### Просмотр истории статусов

```bash
flight-tracker history BA249
```

### Обновление сохранённых рейсов

```bash
flight-tracker refresh
```

Обновление выполняет запросы к Aviationstack для каждого сохранённого рейса.

### Удаление рейса

```bash
flight-tracker remove BA249 --date 2026-11-12
```

Удаление выполняется из локальной базы данных SQLite.

## Демонстрационный режим

Приложение поддерживает работу с демонстрационными данными без API-ключа.

```bash
flight-tracker search SU2134 --demo
```

Демонстрационные данные заранее подготовлены и не отражают реальные статусы авиарейсов.

## Ограничения API

Приложение использует Aviationstack API. Доступные функции и количество запросов зависят от тарифного плана.

Бесплатный тариф имеет следующие ограничения:

- Ограниченное количество API-запросов.
- Отсутствие доступа к историческим данным.
- Ограниченный набор доступных функций API.

Поиск без указания даты использует данные реального времени.

Поиск за произвольную дату и обновление сохранённых рейсов, требующее исторических данных, недоступны на бесплатном тарифе.

При превышении квоты или попытке использования недоступной функции приложение выводит соответствующее сообщение.

Актуальные ограничения:

<https://aviationstack.com/pricing>
